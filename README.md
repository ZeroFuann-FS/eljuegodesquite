# 🥊 El Desquite: Boxea al Pelón 👨‍🦲

Un juego arcade interactivo de boxeo y desahogo de estrés desarrollado con **HTML5 Canvas**, **CSS3** y **JavaScript puro (Web Audio API)**, 100% optimizado para jugar tanto en **teléfonos celulares (Android / iOS)** como en **computadoras de escritorio (PC / Mac)**.

## 📱 Características para Celulares y Pantallas Táctiles

- **Botonera Táctil Ergonómica:** Botones virtuales en pantalla para `IZQ`, `DER`, `UPPERCUT` y `FURIA`.
- **Multitáctil (Multi-touch):** Golpea rápidamente con ambos pulgares al mismo tiempo.
- **Feedback Háptico (Vibración):** El celular vibra con cada puñetazo, golpe crítico y K.O.
- **Soporte PWA y Pantalla Completa:** Se adapta a todas las resoluciones (vertical y horizontal) con soporte para Safe Areas (iPhone Notch).
- **Audio Procedural Instantáneo:** No requiere descargas pesadas de audio; los sonidos se sintetizan en tiempo real.

## 🎮 Controles

### En Celular (Touch):
- Toca directamente sobre la cabeza o cuerpo del pelón para golpear.
- O utiliza la **botonera inferior táctil**:
  - `🥊 IZQ`: Jab / Gancho izquierdo
  - `⚡ UPPER`: Gancho al mentón (Uppercut)
  - `🥊 DER`: Gancho derecho
  - `🔥 FURIA`: Activa el modo frenesí cuando la barra está al 100%

### En PC (Teclado y Ratón):
- **Ratón:** Clic en los lados para jabs/ganchos, y en el mentón para uppercuts.
- **`A` / `←`:** Gancho Izquierdo
- **`D` / `→`:** Gancho Derecho
- **`W` / `↑`:** Uppercut demoledor
- **`S` / `↓`:** Golpe al cuerpo
- **`Espacio`:** ¡Modo Furia!
